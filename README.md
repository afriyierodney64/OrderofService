# Order of Service — PDF Document Viewer

Clean, modern, and responsive web viewer for the Order of Service booklet in celebration of the life of Obaapanin Deborah Asaa Mensah.

## Features
- **Continuous Reading Experience**: Smooth vertical scrolling through all 14 pages.
- **Responsive Layout**:
  - **Mobile**: Clean, full-width document stream with uncrowded header and floating page navigation bar.
  - **iPad & Tablet**: Full-width expanded view with overlay thumbnail sidebar.
  - **Desktop**: Comfortable reading stream with quick-jump thumbnail drawer, zoom, print, and download.
- **Controls**:
  - **Fit Width (Default)**: Expands pages to full width for comfortable reading.
  - **Fit Screen**: Fits pages vertically with smooth page snap scrolling.
  - **Download PDF**: Direct download of the original `splt_organized.pdf`.
  - **Print**: Print-optimized document layout.

## How to Run Locally
Double-click `index.html` or run `start_viewer.bat`.
